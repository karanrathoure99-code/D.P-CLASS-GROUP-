# 📚 D Pharma Class Group

D Pharma छात्रों के लिए एक सुरक्षित, प्राइवेट और एडवांस वेब एप्लिकेशन। इस ऐप का मुख्य उद्देश्य WhatsApp पर निर्भरता खत्म करके क्लास की सभी ज़रूरतों को एक ही जगह सुरक्षित रूप से पूरा करना है।

---

## ✨ मुख्य फ़ीचर्स (Key Features)

- 🔒 **End-to-End Encryption (E2EE):** चैट और मैसेज पूरी तरह से एन्क्रिप्टेड हैं। केवल भेजने वाला और पाने वाला ही इसे पढ़ सकते हैं—सर्वर या कोई तीसरा व्यक्ति नहीं।
- 📝 **नोट्स और स्टडी मटीरियल (Resource Library):** D Pharma के सिलेबस के अनुसार विषयवार (Subject-wise) PDF नोट्स और बुक्स डाउनलोड करने की सुविधा।
- 📤 **असाइनमेंट सबमिशन:** छात्र सीधे ऐप में असाइनमेंट अपलोड कर सकते हैं और टीचर्स वहीं रिव्यू कर सकते हैं।
- 📢 **क्लास नोटिस बोर्ड:** परीक्षा, टाइमटेबल और महत्वपूर्ण सूचनाओं के लिए इंस्टेंट अपडेट्स।
- 👥 **सुरक्षित क्लास कम्युनिटी:** सिर्फ अधिकृत (Verified) छात्रों के लिए ही एक्सेस।

---

## 🛠️ टेक स्टैक (Tech Stack - प्रस्तावित)

- **Frontend:** React.js / HTML5, Tailwind CSS, JavaScript
- **Backend / Database:** Firebase / Node.js
- **Encryption:** Web Crypto API (E2EE)
- **Hosting:** GitHub Pages / Vercel / Firebase Hosting
